## 出口标准（满足即进入 Step2）

- 能说清「字节 → 模型 → CFG」每段产出什么；
- 能默写 4 个插件扩展点；
- 能解释 SSA / AST 现在为什么不动；
- 能解释 JavaFX 主类的坑；
- 能复现默认背景 + 三填充模式 + 导出进度。
