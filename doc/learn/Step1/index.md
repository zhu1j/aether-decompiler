# Step1 · 速查索引（学完回填）

> 用途：这是你**回访**用的索引，不是重读用的长文。每学完一个模块，
> 把「一句话总结 + 一个现实场景」填进对应行；下次只需扫这张表就能唤醒记忆。
>
> 规则（来自学习 skill 的 cruise/index 约定）：**一句话 + 一个场景**，不写段落。

## 模块速查表

| 模块 | 一句话总结 | 现实场景（我在哪用到） | 关联卡点 |
|------|-----------|----------------------|---------|
| 字节码基础 | `.class` = 常量池 + 元数据 + 栈式指令 | 用 `javap -c` 对照 Studio 字节码视图 | 栈式≠寄存器；序号≠行号 |
| 内核架构 | ASM 只在最外层用，进来即转不可变模型 | ASM 升级只改 `aether-core` | 插件永远看不到 ASM |
| 插件契约 | 内核只认 4 个扩展点 | 加一种渲染 = 实现 `RenderPlugin` | 先冻结接口再写实现 |
| 流水线 | 字节→模型→CFG→(SSA)→(AST)→源码 | 右侧流水线面板哪亮哪灰 | SSA/AST 是 Phase2/3，未实现 |
| GUI 外壳 | Application 外壳 + 视图 + 皮肤 + 背景 | `java -jar aether-gui-studio.jar` | Application 子类不能当主类 |

## 4 个扩展点速查

```text
ClassSourcePlugin  提供字节来源     ← jar / 目录
AstTransformPlugin 变换中间表示     ← （Phase2+）
RenderPlugin       渲染成目标格式   ← DOT / Java
AnalysisPlugin     只读分析出指标   ← 度量 / 报告
```

## 流水线阶段速查

```text
Phase0: 读取字节 ▸ 构建模型        ✅ 已实现
Phase1: 控制流图 CFG + 支配树      ✅ 已实现
Phase2: SSA（单静态赋值）          ⏳ 未实现
Phase3: AST（抽象语法树）          ⏳ 未实现
渲染:   Java 源码（当前外包 CFR）  ✅ 借轮子
```

## 一句话记忆钩子

- **字节码** = 原料；**内核** = 工厂；**插件** = 产线接口；**CFG** = 流水线中段。
- **SSA** = 给每次赋值发新名字，让账目清晰。
- **AST** = 把道路图（CFG）重画成建筑蓝图。
- **CFR** = 暂时外包的老师傅，Phase2/3 落地后请他退休。
