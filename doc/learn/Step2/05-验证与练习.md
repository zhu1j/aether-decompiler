## B. 自测题（先写答案，再翻代码）

1. **（本质）** 为什么循环里的累加变量**需要** phi，而直线方法不需要？
2. **（支配边界）** 有一个 if-else，then 与 else 都写变量 x，汇合点在 if 之后。
   x 的支配边界成员是谁？phi 插在哪？
3. **（版本栈）** 下面的 DFS 顺序里，访问 B2 时栈顶是什么？
   `B0{push x0} → B1{push x1} ← 回到B0 → B2`？
4. **（异常边）** 若 try 块里定义了变量、catch 块又使用它，phi 会不会出现在 catch？
   为什么必须把 `exceptionSuccessors` 计入前驱？
5. **（iinc）** `iinc 2 1` 在 SSA 里产生几条记录？分别是 use 还是 def？

<details>
<summary>参考答案（点开前先自己写）</summary>

1. 循环有多条到达路径（0 圈 / ≥1 圈），累加变量在不同路径上版本不同 → 需 phi；
   直线方法每点只有一条到达路径，一个版本足够。
2. 设 then=B1、else=B2、汇合=B3。x 在 B1、B2 定义，B3 的主前驱受 B1/B2 支配但
   B1/B2 不严格支配 B3 → **B3 ∈ DF(B1)**（当 B1 有 ≥2 前驱时）；phi 插在 **B3**。
3. 栈顶是 `x0`（B1 的 `x1` 在离开 B1 时已弹掉）。
4. 会。catch 块经异常边到达，其版本可能来自 try 内或正常流，必须汇合 →
   不计异常边就会漏填/算错支配边界。
5. 两条：一条 use（读旧值）、一条 def（写新版本）。顺序必须是**先 use 后 def**。

</details>
