# Step3 · 02 表达式重建（栈模拟）

> TEACH 第 3 步：微观串行——只解决「栈模拟怎么弹怎么压」这一个卡点。

## 先抛一个猜测（猜测试错）

> 你是不是以为：「读一遍指令，遇到 `iadd` 就写 `+`，遇到 `iload` 就写变量名」？

**方向对，但漏了关键**：字节码是**基于操作数栈**的。`iadd` 不是「写个加号」，而是
「**弹两个、压一个**」。如果你不模拟栈，就不知道这两个操作数分别是哪一个表达式。

正解是：**维护一条表达式栈，逐条指令模拟压栈/弹栈**。

---

## 卡点 ⚠️1：栈模拟的「弹几压几」

### 核心规则

```text
每个指令对表达式栈的影响 = 弹出数 → 压入数
iload_1          : 弹0 压1   → push(Local(slot1))
iconst_5         : 弹0 压1   → push(Const(5))
iadd             : 弹2 压1   → push(Binary("+", pop(), pop()))
istore_1         : 弹1 压0   → 语句: Assign(Local(1), pop())
invokevirtual m  : 弹(argc + 1) 压(1或0) → 可能变成 Call
```

本项目 `ExpressionBuilder.step(...)` 用一个大 `switch(opcode)` 精确实现这套规则。

### 一个具体的推演

```text
字节码:  iload_1 ; iload_2 ; iadd ; istore_1

栈初始:  []
iload_1: [Local(1)]
iload_2: [Local(1), Local(2)]
iadd   : [Binary(+, Local(1), Local(2))]        // 弹 Local(2)、Local(1)，压 Binary
istore_1:[ ]                                     // 弹 Binary → 语句 Local(1)=Binary(...)
```

> ⚠️ **易误判**：`iadd` 弹栈顺序是「先弹右、后弹左」。因为操作数栈先进后出，
> 栈里 `[left, right]`，先 `pop()` 得到 `right`，再 `pop()` 得到 `left`。
> 写反了会变成 `right + left`——多数运算虽可交换，但减法/除法就错了。

## 栈不对称时的兜底（生产级考量）

真实字节码不一定「栈正好平衡」——可能因为异常、或因为块被切分在表达式中间。本项目
对此**永不崩溃**：

```java
private Expr popSafe(int insn) {
    if (stack.isEmpty()) return new Expr.Opaque(insn, "?");   // 空栈兜底
    return stack.pop();
}
```

`Expr.Opaque` 是「这条指令无法精确重建」的诚实标记，它保证：

1. AST 里**永不丢指令**（每条指令都能在某处找到痕迹）；
2. Phase4 源码映射**不会因为缺节点而错位**。

> 这是「玩具实现」与「生产级实现」的分野：前者遇到意外就崩，后者遇到意外就降级、
> 且降级是可观察的。

## 几个高频指令的映射表

| 指令类 | 例子 | 重建为 |
|--------|------|--------|
| 常量 | `iconst_0` / `bipush` / `ldc` | `Const` |
| 取局部变量 | `iload_1` / `aload` | `Local` |
| 算术 | `iadd` / `imul` | `Binary` |
| 自增 | `iinc 2 1` | `Incr` |
| 方法调用 | `invokevirtual`/`static` | `Call`（`desc.endsWith(")V")` 时作为语句） |
| 字段 | `getfield`/`putfield` | `Opaque`（近似字段访问，后续可精细化） |
| 比较分支 | `if_icmpgt` | `Cond(">")`（作为块的终结条件） |
| 返回 | `ireturn`/`return` | `Stmt.Return` |
| 抛出 | `athrow` | `Stmt.Throw` |

> **工程洞察**：方法调用的返回值是否为 `void`，由**描述符**决定：
> `desc.endsWith(")V")` 为真 → 当作语句；否则压栈作为表达式。这就是「用类型信息
> 补足字节码语义」的一个小例子。

## 一句话记住

```text
表达式重建 = 用一条 Deque<Expr> 模拟操作数栈：
  弹几压几要精确，弹序先右后左；意外即 Opaque 兜底，永不崩、永不丢。
```
