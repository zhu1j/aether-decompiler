# Step3 · 03 控制结构恢复（核心卡点）

> TEACH 第 3 步：微观串行——只解决「怎么把跳转还原成 if/while」这一个卡点。

## 先抛一个猜测（猜测试错）

> 你是不是以为：「看到 `if...goto` 就是 if，看到往回跳的 `goto` 就是循环」？

**这是最危险的直觉**，因为：

1. 往回跳的可能是 `while`、`do-while`、`for`，甚至是 `continue`；
2. `if...goto` 的模式在编译后**五花八门**，不能靠字符串匹配；
3. 有些跳转根本**无法**结构化成整齐的 if/while（不可规约）。

正解是：**用支配关系精确识别「回边」与「汇合点」**，而不是模式匹配。

---

## 卡点 ⚠️2：自然循环识别（回边）

### 定义

> 边 `v → s` 是**回边**，当且仅当 `s` **支配** `v`。
> 此时 `s` 是**循环头**，`v` 是回边来源。

为什么？因为「循环」的本质是「有一个入口能再次回到自己」。如果 `s` 支配 `v`，
说明从入口到 `v` 的**所有**路径都经过 `s`——于是 `v → s` 这条边必然构成一个闭环。

```java
for (BasicBlock b : cfg.blocks()) {
    for (int s : normalSuccessors(b.id())) {
        if (dom.dominates(s, b.id())) {     // s 支配 b ⇒ b→s 是回边
            loopHeaders.add(s);             // s 是循环头
            backEdge.put(s, b.id());
        }
    }
}
```

> ⚠️ **易误判**：不要用「序号往回跳」判断循环！`for` 循环里 `continue` 也会往回跳，
> 但它不是循环头。只有**支配关系**才能区分。

### 自然循环 = 回边的两个端点 + 所有能到回边来源的块

识别出回边后，从回边来源反向 BFS，收集所有「能到达它」的块，就是循环体：

```java
Set<Integer> naturalLoop(int header, int backSource) {
    loop.add(header); loop.add(backSource);
    // 反向遍历前驱，凡能到 backSource 的都进循环
}
```

## 卡点 ⚠️3：if-else 的「汇合点」

一个 `if (c) {...} else {...}` 变成两路，之后**必然合流**。合流点是「两个分支都能
到达的第一个块」：

```java
int joinOf(int a, int b) {
    Set<Integer> ra = reachableFrom(a);     // then 分支可达集
    Set<Integer> rb = reachableFrom(b);     // else 分支可达集
    // 取交集里序号最小者 = 最近的公共后继 = 汇合点
}
```

拿到汇合点 `join` 后，就可以安全地递归结构化：

```text
结构 If(cond) {  结构化(then, stop=join)  }
        else {   结构化(else, stop=join)  }
```

`stop=join` 保证递归**到汇合点停**，不会越界到外层。

## 卡点 ⚠️4：不可规约时的诚实降级

有些控制流（尤其被混淆的字节码）**无法**规约成嵌套结构——例如多入口环路：

```text
      ┌──────┐
      ↓      │
  A → B ⇄ C  │      两个块互相跳，谁也不是对方的支配者
      ↑      │
      └──────┘
```

此时本项目**不猜、不伪造**，而是退回「标签 + 线性块」模式：

```java
private Stmt linearFallback() {
    for (BasicBlock b : cfg.blocks()) {
        out.add(new Stmt.Label(..., "L" + b.id()));   // 打标签
        out.addAll(reconstruct(b.id()).statements());  // 原样保留语句
    }
}
```

并置位 `irreducible = true`，由 GUI / 渲染器如实告知用户。

> **设计哲学**：反编译器的可信度，取决于它**在无法确定时敢不敢说不知道**。
> 输出「// irreducible」远好于输出一个看似合理但错误的 if/while。

---

## 递归下降的骨架

```text
region(entry, stop, depth):
    while cur != stop 且 cur 未发射:
        if cur 是循环头:      cur = 结构化循环
        elif cur 以条件跳转结尾: cur = 结构化 if-else（到 join）
        else:                 发射本块语句; cur = 唯一后继
```

三个分支分别对应：循环、条件、顺序——覆盖了结构化控制流的所有情形。

---

## 一句话记住

```text
回边 = 后继支配前驱 → 循环头。
汇合点 = 两分支可达集交集的最近者 → if-else 的边界。
不可规约 → 诚实降级为标签，不伪造。
```
