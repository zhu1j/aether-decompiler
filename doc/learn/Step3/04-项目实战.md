## 编排器：三步走

```java
public MethodBody build(ClassModel owner, MethodModel method) {
    ControlFlowGraph cfg = cfgBuilder.build(owner, method);   // 1. 建 CFG
    DominatorTree dom = DominatorTree.of(cfg);                // 2. 建支配树
    ControlStructurer structurer = new ControlStructurer(cfg, dom);
    Stmt body = structurer.structure();                       // 3. 结构化
    return new MethodBody(owner.name(), method.name(), method.descriptor(),
            method.access(), body, structurer.isIrreducible());
}
```

> 注意：流水线（Phase5）会**复用**已算好的 cfg/dom，走另一个 `build(...)` 重载，
> 避免重复计算——这是「接口分层」的收益。

## ControlStructurer 的关键片段

### (a) 回边检测 → 循环头

```java
for (BasicBlock b : cfg.blocks()) {
    for (int s : normalSuccessors(b.id())) {
        if (dom.dominates(s, b.id())) {          // s 支配 b ⇒ 回边
            loopHeaders.add(s);
            backEdge.put(s, b.id());
        }
    }
}
```

### (b) 循环的「继续条件」如何取

```java
// 若条件分支的目标在循环外，说明「跳出」= cond，则「继续」取反
cond = (outside >= 0 && succs.get(0) == outside)
        ? negate(r.terminatorCond(), header)
        : r.terminatorCond();
```

> 这是最容易写错的地方：`while(c)` 编译后常见「条件为假就跳出」，所以要**取反**才是
> 循环继续条件。本项目用 `negate(...)` 显式处理 `Cond` 的 `negated` 标志。

### (c) if-else 汇合点

```java
int join = joinOf(thenB, elseB);     // 两分支可达集交集的最近者
branchJoin.put(block, join);
Stmt thenStmt = region(thenB, join, depth + 1);
Stmt elseStmt = (elseB == join) ? null : region(elseB, join, depth + 1);
```

### (d) 诚实降级

```java
private Stmt linearFallback() {
    for (BasicBlock b : cfg.blocks()) {
        out.add(new Stmt.Label(b.firstInsn(), "L" + b.id()));
        out.addAll(reconstruct(b.id()).statements());
    }
    return new Stmt.Block(0, Math.max(0, insns.size() - 1), out);
}
```

## 指令 → 节点 的完整映射（速查）

| 指令 | 节点 |
|------|------|
| iconst/bipush/ldc | `Expr.Const` |
| iload/aload | `Expr.Local` |
| iadd/imul/... | `Expr.Binary` |
| ineg/i2l | `Expr.Unary` |
| iinc | `Expr.Incr` |
| istore | `Expr.Assign` → `Stmt.ExprStmt` |
| invoke* | `Expr.Call`（void → 语句） |
| new | `Expr.New` |
| checkcast/instanceof | `Expr.Cast` / `Expr.InstanceOf` |
| iaload/iastore | `Expr.ArrayLoad` / `Expr.ArrayStore` |
| if_icmp* | `Expr.Cond`（块终结条件） |
| ireturn/return | `Stmt.Return` |
| athrow | `Stmt.Throw` |
| goto | 由结构恢复消化；不可规约时 `Stmt.Goto` |

## JavaAstRenderer：AST 如何变成 Java

- 遍历语句树，按缩进逐行输出；
- **每写一行，就把该行绑定到语句的指令区间**（`emitLine`）：
  ```java
  mapping.add(startLine, startCol, startLine, startCol + text.length(), is, ie, -1);
  ```
- 于是渲染完成时，源码映射也同步完成——见 Step4。
