## B. 自测题（先写答案，再翻代码）

1. **（本质）** 为什么 AST 节点里不能直接存 `"a + b"` 这样的字符串？
2. **（栈模拟）** `iload_1 ; iload_2 ; isub` 重建出的表达式是什么？注意顺序。
3. **（回边）** 为什么不能靠「目标序号小于当前」来判断回边？
4. **（汇合点）** 若 then 分支内部又有一个 if，`joinOf(then, else)` 还会正确吗？为什么？
5. **（降级）** 什么情况下会输出 `Label`/`Goto`？这是缺陷还是设计？

<details>
<summary>参考答案（点开前先自己写）</summary>

1. 因为同一棵树要能渲染成多种语言；一旦焊入 Java 记号就失去中立性。
2. `Binary("-", Local(1), Local(2))`。`isub` 先弹右（Local2）再弹左（Local1）。
3. 因为 `for` 的 `continue` 也会往回跳，但不是循环头；只有「后继支配前驱」才是回边。
4. 会。`joinOf` 求的是两分支**可达集的交集最近者**，与分支内部嵌套多少层无关。
5. 控制流不可规约（多入口环路/乱跳）时；这是**刻意的诚实降级**，不是缺陷。

</details>
