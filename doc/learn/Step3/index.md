## 模块速查表

| 模块 | 一句话总结 | 现实场景 | 关联卡点 |
|------|-----------|---------|---------|
| AST 本质 | 把「线性+跳转」变成「嵌套+层次」 | 反编译/重构/Lint | AST 不含关键字 |
| 表达式重建 | 用表达式栈模拟操作数栈 | 还原 `a+b` 这类式子 | ⚠️弹序先右后左 |
| 语句树 | ExprStmt/If/While/Return/TryCatch | 输出可读源码 | 节点带指令区间 |
| 回边识别 | 后继支配前驱 ⇒ 循环头 | 认出 while/for | ⚠️别用序号判循环 |
| 汇合点 | 两分支可达集交集的最近者 | if-else 边界 | ⚠️嵌套也正确 |
| 诚实降级 | 不可规约 → 标签+线性 | 混淆代码 | ⚠️不伪造结构 |

## 核心不变量

```text
1) AST 语言中立：节点只描述结构，不含关键字。
2) 每个节点携带 firstInsn/lastInsn → 源码映射锚点。
3) 结构恢复失败时降级为 Label/Goto，标记 irreducible。
```

## 算法速记

```text
region(entry, stop):
  循环头?   → 结构化 while
  条件跳转? → 结构化 if-else（到 join）
  否则      → 发射顺序块，走唯一后继
```

## 一句话记忆钩子

- **AST** = 把道路图重画成建筑蓝图。
- **表达式重建** = 一条栈走到底。
- **回边** = 循环头（用支配判，不用序号）。
- **降级** = 不确定时诚实说不知道。
