# Step4 · 02 边渲染边映射（核心）

> TEACH 第 3 步：微观串行——只解决「映射在何时、如何被建立与查询」。

## 先抛一个猜测（猜测试错）

> 你是不是以为：「映射是一张预先算好的静态表」？

**更准确的说法**：映射是**渲染过程的副产品**。渲染器每输出一行，就登记一个 span；
渲染结束，映射自然完备。这样避免了「文本 → 结构」的反解析。

## 建立：渲染时的登记

本项目 `JavaAstRenderer.emitLine(...)`：

```java
private void emitLine(AstNode node, String text) {
    for (int i = 0; i < indent; i++) emit("    ");
    int startLine = line, startCol = col;
    int is = node == null ? -1 : node.firstInsn();
    int ie = node == null ? -1 : (node.lastInsn() + 1);      // 半开区间：+1
    mapping.add(startLine, startCol, startLine, startCol + text.length(), is, ie, -1);
    out.append(text).append('\n');
    line++; col = 0;
}
```

要点：

1. **先记坐标，再写文本**：`startLine/startCol` 必须在 append 之前取；
2. **区间半开**：`ie = lastInsn + 1`，与查询逻辑一致；
3. **-1 表示未知**：无指令来源（如纯装饰行）用 `-1`。

## 查询：两个方向

### 正向（接口承诺）：`atGenerated(line, col)`

```java
public Span atGenerated(int generatedLine, int generatedCol) {
    Span exact = byStart.get(key(generatedLine, generatedCol));
    if (exact != null) return exact;
    for (Span s : spans)                       // 退化：命中同行、列落入区间
        if (s.generatedStartLine() == generatedLine
                && generatedCol >= s.generatedStartCol()
                && generatedCol < Math.max(s.generatedEndCol(), s.generatedStartCol() + 1))
            return s;
    return null;
}
```

用途：用户在编辑器里点了某处 → 找到它对应的字节码区间。

### 反向（本实现增强）：`atInsn(insnIndex)`

```java
public List<Span> atInsn(int insnIndex) {
    for (Span s : spans)
        if (insnIndex >= s.insnStart() && insnIndex < Math.max(s.insnEnd(), s.insnStart() + 1))
            out.add(s);
    return out;
}
```

用途：用户在字节码视图选中一条 → 高亮所有由它生成的源码行。

> ⚠️ **卡点 ⚠️3**：`SourceMapping` 接口**只承诺**正向查询。反向查询是本实现
> `DefaultSourceMapping` 的**能力增强**。这提示一个设计经验：**接口保持最小、实现按需增强**——
> 既满足契约，又不牺牲实用性。

## 索引结构

```java
Map<Long, Span> byStart;   // key = (line<<32) | col，O(1) 命中「行首」
List<Span> spans;          // 保序，供区间查询与遍历
```

> **工程洞察**：把 `(line, col)` 打包成一个 `long` 键，比 `Map<Point, Span>` 更省、
> 更快，也避免自定义 key 的 equals/hashCode 成本。

## 一句话记住

```text
映射 = 渲染的副产品：写一行 → 记一 span（半开区间）。
正向 O(1) 命中行首，反向线性扫区间；接口只承诺正向，反向是按需增强。
```
