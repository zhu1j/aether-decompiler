# Step4 · 速查索引（学完回填）

## 模块速查表

| 模块 | 一句话总结 | 现实场景 | 关联卡点 |
|------|-----------|---------|---------|
| Span | 生成坐标 + 指令区间 + 原始行 | 点击跳转 | ⚠️半开区间 |
| 锚点来源 | AST 节点天生带 firstInsn/lastInsn | 映射不丢 | ⚠️非事后解析 |
| 边渲染边映射 | 写一行 → 记一 span | 渲染器产出 | emitch 时机 |
| 正向查询 | atGenerated(line,col)，O(1) 命中行首 | 源码→字节码 | 接口承诺 |
| 反向查询 | atInsn(idx)，线性扫区间 | 字节码→源码 | ⚠️接口未承诺，增强 |

## 核心不变量

```text
1) 映射是渲染的副产品，不做文本反解析。
2) 指令区间半开：insnEnd 不含尾。
3) 无指令来源的 span 用 -1。
```

## 一句话记忆钩子

- **Span** = 三侧坐标（生成/指令/源码）。
- **锚点** = AST 的基因。
- **映射** = 渲染副产品。
- **正向接口 / 反向增强** = 最小接口 + 实用实现。
