# Step5 · 速查索引（学完回填）

## 模块速查表

| 模块 | 一句话总结 | 现实场景 | 关联卡点 |
|------|-----------|---------|---------|
| 流水线 | 模型→CFG→Dom→SSA→AST 串起来 | 一次调用拿全部产物 | 阶段依赖 |
| 缓存 | 不可变产物按「类#方法」缓存 | 避免重复计算 | ⚠️必须不可变 |
| 并发写入 | putIfAbsent 保证同键同实例 | 多线程同名方法 | ⚠️勿用 put |
| 并行 | 类级并行、注入线程池 | 批量反编译 jar | ⚠️内核不拥有池 |
| 异常传递 | Future.get 重新抛出 | 并行子任务失败 | ⚠️别吞异常 |
| 事件 | 阶段完成发布，界面呈现 | GUI 进度点亮 | 解耦 |

## 核心不变量

```text
1) 缓存的产物必须不可变。
2) 同一 key 永远返回同一实例（putIfAbsent）。
3) 内核不拥有线程池，只接受注入。
4) 并行结果顺序与输入一致，异常可穿透。
```

## 一句话记忆钩子

- **流水线** = 串起五个阶段。
- **不可变** = 缓存的通行证。
- **注入线程池** = 内核不越权。
- **事件** = 引擎说「发生了什么」，界面决定「怎么显示」。
